# CellSim 名前空間
シミュレータ全体を制御するクラスが含まれています。

## クラス
| クラス名 | 説明 |
| :--- | :--- |
| [Messages](./Messages/README.md) | 実行時に画面に表示するメッセージを管理します。 |
| [Simulation](./Simulation/README.md) | シミュレーション全体を管理します。 |
| [SimulationOption](./SimulationOption/README.md) | シミュレーションで使用するオプションと出力ディレクトリを定義します。 |
| [SimulationResultWriter](./SimulationResultWriter/README.md) | シミュレーション結果を出力する機能を提供します。 |
| [Version](./Version/README.md) | CellSimのバージョン情報を提供します。 |

## 列挙型
| 型名 | 説明 |
| :--- | :--- |
| [PeformanceType](./PeformanceType/README.md) | 実行時のパフォーマンス設定を表します。 |
