# cellAlgorithm パラメーター
最適化アルゴリズムの各種パラメーターを設定します。

```json
"cellAlgorithm": {
    "type": "object"
}
```

## 必須パラメーター
| 名前 | 説明 |
| :--- | :--- |
| [algorithmType](./algorithmType/README.md) | 使用する最適化アルゴリズムの種類を選択します。 |
| [useClusterModel](./useClusterModel/README.md) | クラスタモデルを使用するかを選択します。 |

## 任意パラメーター
| 名前 | 説明 |
| :--- | :--- |
| [cellList](./cellList/README.md) | CellList独自のパラメーターを設定します。 |
| [useClusterModel](./useClusterModel/README.md) | クラスタモデルを使用するかを選択します。 |
