# fieldRadius プロパティ
シミュレーション空間の範囲を指定します。

```json
"fieldRadius": {
    "type": "number",
    "minimum": 0,
    "examples": [
        512,
        1024,
        2048
    ]
}
```

## 型
`number`

## 値の範囲
`value >= 0`

## 解説
シミュレーション開始時に細胞は原点を中心とした半径`value`の円または球の内部に配置されます。
分子空間は原点を中心とした1辺`value`の正方形または立方体の内部に配置されます。
