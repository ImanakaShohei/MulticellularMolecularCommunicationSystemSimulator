# behaviorParameters パラメーター
使用するBehaviorのパラメーターを指定します。

```json
"behaviorParameters": {
    "type": "object"
}
```

## 任意パラメーター
| 名前 | 説明 |
| :--- | :--- |
| [moleculeAware](./moleculeAware/README.md) | MoleculeAwareCellBehaviorのパラメーターを指定します。 |
| [normal](./normal/README.md) | NormalCellBehaviorのパラメーターを指定します。 |
