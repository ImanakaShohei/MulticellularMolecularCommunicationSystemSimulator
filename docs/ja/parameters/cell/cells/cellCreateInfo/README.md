# cellCreateInfo パラメーター
配置する細胞の情報を設定します。

```json
"cellCreateInfo": {
    "type": "object"
}
```

## 必須パラメーター
| 名前 | 説明 |
| :--- | :--- |
| [behaviorParameters](./behaviorParameters/README.md) | 使用するBehaviorのパラメーターを指定します。 |
| [behaviorType](./behaviorType/README.md) | ふるまいの種類を指定します。 |
| [cellCount](./cellCount/README.md) | 初期配置する細胞数を指定します。 |
| [color](./color/README.md) | 画像・動画出力時の色を指定します。 |
| [mass](./mass/README.md) | 初期配置時の細胞の質量を指定します。 |
| [radius](./radius/README.md) | 初期配置時の細胞の半径を指定します。 |
| [typeName](./typeName/README.md) | 細胞の種類に名前を付けます。 |
