# cell パラメーター
細胞に関する設定。

## 必須パラメーター
| 名前 | 説明 |
| :--- | :--- |
| [cells](./cells/README.md) | 配置する細胞の情報を格納します。 |
| [enableGrowth](./enableGrowth/README.md) | 細胞が成長するかを指定します。 |
| [initialPlacementRadius](./initialPlacementRadius/README.md) | 細胞の初期配置の範囲を指定します。 |
| [initialPlacementSeed](./initialPlacementSeed/README.md) | 細胞の初期配置の位置を決めるランダム生成器の種を指定します。 |
| [isSensitiveToMolecules](./isSensitiveToMolecules/README.md) | 細胞が分子空間の影響を受けるかを指定します。 |
